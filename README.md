# Дыхание

Тренажёр дыхания для телефона. Точка идёт по сторонам фигуры, лёгкие наполняются и освобождаются, а звук позволяет заниматься с закрытыми глазами.

## Установить на телефон

Откройте страницу приложения в Chrome на телефоне и выберите в меню «Установить приложение». На рабочем столе появится иконка, и дальше приложение работает без интернета.

## Как устроено

Обычная веб-страница без сборки: открывается двойным щелчком по `index.html`.

| Файл | Что делает |
| --- | --- |
| `index.html`, `styles.css` | разметка и оформление обоих экранов |
| `app.js` | программы, цикл дыхания, настройки |
| `figure.js` | геометрия фигуры: где идёт точка и куда помещаются лёгкие |
| `backgrounds/` | живые фоны, по файлу на фон (контракт описан в `registry.js`) |
| `sound/` | звук: ядро `engine.js` и четыре режима звучания |
| `sw.js`, `manifest.webmanifest` | работа без интернета и установка на телефон |

### Программы

Четыре длительности в секундах: вдох, задержка на вдохе, выдох, задержка на выдохе. Стандартные программы — «Спокойствие» 4-0-6-0, «Фокус» 4-4-4-4, «Расслабление» 4-0-8-0, «Сон» 4-7-8-0, «Бодрость» 6-0-2-0, «Баланс» 5-0-5-0. Свои программы добавляются в настройках.

### Разработка

```
node dev-server.js
```

Затем откройте http://localhost:8137 — или `design.html`, где оба экрана видны рядом, и `backgrounds/preview.html`, где видны все фоны.

Проверки:

```
node tests/figure.test.js
node tests/background.smoke.js backgrounds/*.js
node tests/background.seam.js backgrounds/*.js
node tests/sound.test.js sound/bell.js sound/ladder.js sound/tone.js sound/wave.js
```

Иконки перерисовываются страницей `tools/make-icons.html` при запущенном `dev-server.js`.

## Предупреждение

Это не медицинское приложение. Дышите мягко, не на полную грудь, сидя или лёжа. Закружилась голова — остановитесь и дышите как обычно. При беременности, болезнях сердца и лёгких, эпилепсии или панических атаках сначала посоветуйтесь с врачом и не делайте задержек дыхания.
